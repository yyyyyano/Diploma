# Дизайн-система «Пуща и янтарь» (`apps/web/src/ui`)

Источник вида — `design/DESIGN.md`, `design/tokens.css`, `design/kit.css`; SPEC §7 (DES-01…17); ADR-0014.

- `ui/` — **только представление**: Mantine, `@kosht/i18n` (форматы), `@kosht/kernel` (типы). Без `lib/api`,
  `lib/events`, `entities`, `features`, без запросов и бизнес-правил.
- Цвета, шрифты, радиусы, тени — только токены: `ui/theme/tokens.css` — копия `design/tokens.css` по значениям
  (написание — oxfmt) плюс токены SPEC §7.1, которых нет в макете (сейчас `--warn-bar`); правка — в `design/` и
  SPEC §7. Прочие значения набора (оттенки меню, подложки, тени, шкала отступов `--s-<px>`, радиусы `--r-xs…--r-pill`)
  — `ui/theme/kit.css`, только из `design/kit.css` и каркаса телефона макета (новых цветов нет — `theme.test.ts`).
  Тема Mantine ссылается на `var(--brand)` и т. д.; цвета категорий и графиков — таблицы
  `ui/theme/category-colors.ts`, `chart-colors.ts`. «Сырые» цвета и числа отступов вне `ui/theme` ловит
  `no-raw-colors.mjs`.
- Роли цветов не смешивать: хвоя — действия; **янтарь — только найденная выгода**; `--warn` — текст и бейджи
  внимания (всегда с треугольником); `--danger` — риск и ошибка (всегда с «!»); `--law` — право; доход — `--income`
  со знаком «+». Полоса лимита: до 80 % — `--brand`, 80–99 % — `--warn-bar` `#C2700E` (графика, ≥ 3:1) +
  треугольник, ≥ 100 % — `--danger` + «!».
- Шрифты: Onest — всё; Literata — **только** дословные тексты законов (`LawQuote`); табличные цифры в таблицах и
  колонках, пропорциональные — в заголовках и тексте; моноширинного шрифта нет. Подключение — `@fontsource-variable`.
- Компонент обязан сам обеспечивать доступность: `StatusBadge` требует иконку (без неё не компилируется),
  `WhyButton` — `aria-label` с названием числа, кнопки-иконки — `aria-label`; настоящие `button`/`a`/`label`;
  Esc закрывает панель и возвращает фокус; фокус — обводка 2 px `--brand`; контраст текста ≥ 4,5:1, графики ≥ 3:1;
  `prefers-reduced-motion` учитывается.
- `Money` — формат DES-17 (`1 234,56 BYN`, неразрывный пробел, валюта мельче) через `formatMoney`; знак и цвет — по
  `kind` (доход/расход/перевод). Даты — `formatDate` (`21.10.2026`).
- Каждый компонент и каждое его состояние — в `/dev/gallery`; компонентный тест на состояния и роли.
- Иконки — Lucide (24×24, контур 1,8); эмодзи в интерфейсе нет. На диаграмме до 6 рядов, остальное — «Остальное».

Правильно:

```tsx
export function StatusBadge({ tone, icon: Icon, children }: { tone: StatusTone; icon: LucideIcon; children: ReactNode }) {
  return (
    <Badge variant="light" className={classes[tone]} leftSection={<Icon size={14} aria-hidden />}>
      {children}
    </Badge>
  );
}
```

Нельзя: `color="#11564D"` или `style={{ padding: 13 }}`; янтарь для предупреждения; статус только цветом; текст
литералом внутри компонента (подписи — пропсами или `t()`); запрос данных из `ui/`; новый токен без строки в SPEC §7.1.
