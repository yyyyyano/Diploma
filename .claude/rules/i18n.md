# Тексты и форматы (i18n, NFR-19, DES-17)

- Весь текст для человека — через словари `packages/i18n` (ru; be — задел): сайт — `t()` (react-i18next), бот, письма,
  уведомления — тот же словарь на сервере. Литерал в JSX или в тексте сообщения бота ловит `make check`.
- Ключи: `<ns>:<экран>.<ключ>` — `operations:bulk.confirmTitle`; пространства имён по фичам + `common`, `errors`
  (по кодам `AppError`), `formulas` (подписи трасс «Откуда эта цифра?»), `tools` (подписи шагов агента). Ключи
  типизированы — несуществующий ключ не компилируется.
- Множественные числа — правилами i18next для русского (`_one`, `_few`, `_many`): «12 операций», «1 операция».
- Параметры — подстановкой, не склейкой строк: `t("receipts:duplicate", { date })`.
- Суммы — только `formatMoney` (`1 234,56 BYN`, неразрывный пробел между разрядами, запятая перед копейками); даты —
  `formatDate` (`21.10.2026`), относительные («завтра», «через 4 дня») — `formatRelativeDay`; всё по `Europe/Minsk`
  (`Intl`, NFR-23). Валюта — код ISO, не символ.
- Тон (AGT-09, DESIGN.md §6): на «вы», коротко, без жаргона, термины поясняются в скобках; кнопка — глагол
  («Импортировать 35», «Да, перенести 13»), а не «ОК»; ошибка — что случилось и что сделать.
- Модель пишет только текст ответа ассистента; подписи интерфейса, шагов, карточек — из словаря.
- Машинные имена (коды ошибок, события, ключи логов) не переводятся и пользователю не показываются.

Правильно:

```tsx
<Text>{t("operations:found", { count: total })}</Text>          // «Найдено 47 операций»
<Money value={op.amount} kind={op.type} tabular />              // формат — внутри ui/Money
```

Нельзя: `"Найдено " + n + " операций"`; `amount.toFixed(2) + " руб."`; `toLocaleString()` без локали и пояса;
английские строки в интерфейсе (кроме Langfuse — он инструмент разработчика); текст ошибки с сервера в UI.
