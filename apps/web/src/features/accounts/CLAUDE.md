# Экран `accounts` — Счета

Маршрут: `/accounts` (`routes/_app/accounts.tsx`) · доступ: пользователь (без сессии — `/login`). Пункт меню —
«Деньги → Счета».

## Макет
- Исходник: `design/screens/Accounts.dc.html`; описание — `design/SCREENS.md` § «Счета».
- Скриншоты: `design/screenshots/desktop/Accounts.png`, `design/screenshots/mobile-width/Accounts.png`.

## Требования SPEC
STMT-01 («Наличные» с самого начала); состояния — DES-16; доступность — NFR-20.

## Данные (контракт)
- Чтение: `orpc.accounts.list` — счета домохозяйства («Наличные» первыми), `loader` — `prefetchQuery` (ошибку
  показывает страница). Контекст ассистента: `staticData.page = "accounts"`.
- Живые обновления: `events.stream` (`changed`, `account`) → перезапрос активных запросов (`lib/events`).

## Компоненты
Свои: `AccountsPage`. Из `entities`: `account` (`AccountCard`). Из `ui`: `PageHeader`, `Money`, `EmptyState`,
`SkeletonCard`.

## Переходы
Нет (операции счёта — T-021).

## Отличия от макета (с причиной)
- Только список: итоги «Всего на счетах», «Доступно без накопительного», «Валюта», «Добавить счёт», меню счёта,
  график остатка, «Карта, не указана» и блок «Как Кошт считает остатки» — T-019 (остатки, курсы, виды счетов).
- У остатка нет ⓘ «Откуда эта цифра?»: трассы остатка ещё нет (T-019), панель — T-014.
