# Экран `dev-gallery` — витрина дизайн-системы

Маршрут: `/dev/gallery` (`routes/dev.gallery.tsx`) · доступ: только разработка (`vite`) и сборка `--mode e2e`; в боевой
сборке маршрута нет (`routeFileIgnorePattern` в `apps/web/vite.config.ts`).

## Макет
- Компоненты: `design/kit.css`, `design/DESIGN.md` §4; каркас — `design/screens/Main.dc.html` (боковое меню),
  `design/screens/MobileHome.dc.html` (нижняя панель телефона).

## Требования SPEC
DES-01…17 (вид), NFR-20 (доступность), P9; ADR-0013 — витрина вместо Storybook.

## Данные (контракт)
Нет: демонстрационные значения в коде витрины; запросов к серверу нет (выбор категории — демо-справочник в кэше
запросов, без перезапроса). Тексты — литералами (витрина не продукт;
путь пропущен в `tooling/checks/jsx-literals.mjs`).

## Компоненты
Все из `ui/index.ts` во всех состояниях; каркас — `SideNav` (меню DES-15 целиком, с пользователем) и `BottomNav`
(с кнопкой «Чек» и шторкой «Ещё») из `ui/shell`. Панель, подтверждения и уведомление — по кнопкам; панель —
`ExplanationView` из `entities/explanation` на трассе свободного остатка (FIN-20, ключи `TRACE_KEYS`); `CategoryIcon`
и `CategoryPicker` из `entities/category` (встроенные расходные категории, «Новая категория»).

## Переходы
Нет: ссылки демо-меню — якоря страницы.

## Отличия от макета (с причиной)
- Меню показано блоком на странице, а не каркасом: витрина открывается без входа и проверяет компонент, а не раскладку.

## Готово, когда
Новый компонент `ui/` или его состояние добавлены сюда в той же задаче; `make e2e` — axe 0 нарушений на 1440 и 390,
без горизонтальной прокрутки (в том числе с открытыми панелью, подтверждением и уведомлением).
