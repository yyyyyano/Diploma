# Экран `laws` — «База законов»: каталог, поиск по статье, читалка

Маршруты (`routes/_public/`): `/laws` (каталог, адрес — `?group=&status=&q=`), `/laws/$pravoId` (читалка, `?article=` — ключ статьи `210`, `216.1` или
части `p:2`). Открыты всем (`publicProc`, LEGAL-11): `laws.tsx` — раскладка маршрута: вошедший — в каркасе `Shell` (пункт меню «База законов», группа
«Право и выгода»), гость — в `GuestFrame` без меню («Войти», «Регистрация»). Сессия в кэше: гость — `null`.

## Макет
- `design/screens/Laws.dc.html` (`Laws--article-reader`, `Laws--guest`), `design/SCREENS.md` § «База законов», скриншоты `desktop|mobile-width/Laws.png`.
- Отличия от макета: без реквизитов «№ … от …» в строке акта (в каталоге их пока нет — только вид и краткое имя); без плашки «Касается вас»
  и кнопок «Спросить ассистента» (чат — T-043, вычеты — T-046); демо-цифры макета не перенесены.

## Требования SPEC
LEGAL-11, LEGAL-05, LEGAL-06, LAW-07, LAW-32, DES-06, DES-12, DES-16, NFR-20.

## Данные (контракт)
- `orpc.legalBase.catalog` (все акты: состояние `active | has-changes | card-only | repealed`, группа, день редакции, счётчики), `act({ pravoId })`
  (акт, оглавление, принятые изменения, ссылки на pravo.by), `fragments({ pravoId, key })` (текст одной статьи или страницы акта без статей — весь НК
  одним запросом не грузится), `resolve({ q })` («ст. 210 НК» → акт и статья; запрос — когда человек перестал печатать, 300 мс).
- Поиск по названию — на клиенте по готовому списку; фильтры и поиск живут в адресе (`model/search.ts`: `q` не обрезается — пробелы нужны при наборе;
  `article` принимает и число, роутер читает `?article=210` числом).
- Страницы — `lazyPage` (бюджет первой загрузки); `LawStatusBadge` — `entities/law`; `LawRefChip`, `LawQuote` — `ui/components`.

## Состояния и доступность
Загрузка, пусто, ошибка, успех (DES-16); поиск без результатов — сброс; акт «только карточка» — без текста, со ссылкой; предупреждение о принятых
изменениях — по очереди LAW-32. axe 0 при 1440 и 390 — `e2e/specs/first-run.spec.ts` (гость, вошедший, читалка, «только карточка»).
