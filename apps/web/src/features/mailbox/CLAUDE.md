# Экран `mailbox` — Локальный почтовый ящик

Маршрут: `/mailbox` (`routes/_local/mailbox.tsx`) · доступ: только localhost, без входа (на сетевом входе сервер
отвечает `NOT_FOUND` — страница показывает ошибку).

## Макет
- Исходник: `design/screens/Mailbox.dc.html`; описание — `design/SCREENS.md` § «Локальный почтовый ящик (демо)».
- Скриншоты: `design/screenshots/desktop/Mailbox.png`, `design/screenshots/mobile-width/Mailbox.png`.

## Требования SPEC
AUTH-06 (ящик для демо и разработки), NFR-24; состояния — DES-16; доступность — NFR-20.

## Данные (контракт)
- Чтение: `orpc.mail.mailbox` — `{ enabled, messages }` (новые сверху); «Обновить» — повторный запрос.
- Изменений нет: «прочитано» — состояние окна (точка у непрочитанных, первое письмо открыто сразу).
- Контекст ассистента: `staticData.page = "mailbox"`.

## Компоненты
Свои: `MailboxPage`, `Letter`. Из `ui`: `Logo`, `EmptyState`, `SkeletonList`. Mantine: `Button`.

## Переходы
«Ко входу» → `/login`; кнопка письма — ссылка из письма (подтверждение адреса `/verify-email`, сброс пароля).

## Отличия от макета (с причиной)
- Вместо времени письма («10:12», «Вчера») — день «26.10.2026»: формата времени суток в `@kosht/i18n` нет, пояс —
  системный по умолчанию (NFR-23); письма и так новые сверху.
- «Прочитано» не хранится на сервере: ящик — страница демо, не почтовый клиент.
- Почта настроена — пустое состояние «Почта настроена» вместо списка (AUTH-06: ящик выключен).
