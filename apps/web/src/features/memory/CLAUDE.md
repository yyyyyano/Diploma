# Экран `memory` — Что ассистент знает обо мне

Маршрут: `/memory` (`routes/_app/memory.tsx`) · доступ: пользователь (без сессии — `/login`). Пункт меню —
«Профиль → Что ассистент знает».

## Макет
- Исходник: `design/screens/Memory.dc.html`; описание — `design/SCREENS.md` § «Что ассистент знает обо мне».
- Скриншоты: `design/screenshots/desktop/Memory.png`, `design/screenshots/mobile-width/Memory.png`.

## Требования SPEC
PROF-03 (предположение → «Верно»), PROF-05 (факты по темам, источник, дата, статус; подтвердить, исправить, удалить),
PROF-06 (возраст детей — оценка сервера на сегодня), P5 («Отменить»); состояния — DES-16; доступность — NFR-20.

## Данные (контракт)
- Чтение: `orpc.profile.facts` — действующие факты с оценкой на сегодня; `loader` — `prefetchQuery`. Контекст
  ассистента: `staticData.page = "memory"`.
- Изменение (одиночное → `UndoActionToast`): `setFact` («Указать», «Исправить», «Добавить факт» — заметка),
  `confirmFact` («Верно», «Да, верно»), `deleteFact` («Удалить»). «Отменить» отменённого позже — текст «уже изменили».
- Живые обновления: `events.stream` (`profile-fact`) → перезапрос.

## Компоненты
Свои: `MemoryPage` (`AssumptionCheck`, `FactRow`). Из `entities`: `profile-fact` (`FactEditor`, `FactValueText`,
`factLabel`, `keyLabel`), `action` (`UndoActionToast`). Из `ui`: `PageHeader`, `StatusBadge`, `EmptyState`,
`SkeletonCard`; окно формы — `Modal` Mantine.

## Переходы
«Скачать все мои данные» → `/settings?tab=my-data`.

## Отличия от макета (с причиной)
- «Спросить позже» прячет предположение до перезагрузки страницы (сервер не хранит «отложено» — вопрос не о данных).
- «Свободный остаток: сейчас … BYN» и «Спросить ассистента» на странице — без числа и кнопки: расчёт — T-031, панель
  чата — T-043.
- Зарплата-предположение без «Откуда эта цифра?»: вывод фактов по выпискам и его трасса — T-031.
