# Экран `onboarding` — Анкета на 1 минуту

Маршрут: `/onboarding` (`routes/onboarding.tsx`, без каркаса — своя шапка со знаком) · доступ: пользователь (без
сессии — `/login`; анкету уже прошли или пропустили — на «/»). Стартовый «/» ведёт сюда, пока анкета `pending`.

## Макет
- Исходник: `design/screens/Onboarding.dc.html`; описание — `design/SCREENS.md` § «Анкета на 1 минуту».
- Скриншоты: `design/screenshots/desktop/Onboarding.png`, `design/screenshots/mobile-width/Onboarding.png`.
- Состояния: `design/screenshots/states/Onboarding--question-2.png` (дети: счётчик).

## Требования SPEC
AUTH-07, PROF-02 (шесть вопросов, каждый пропускается); состояния — DES-16; доступность — NFR-20.

## Данные (контракт)
- `orpc.profile.completeOnboarding({ answers })` — «Готово» после шестого вопроса (только отвеченные), «Пропустить
  анкету» — пустые ответы и переход на «/». Признак «пройдена или пропущена» хранит сервер (`profile.onboarding`).
- Итог «Вот что я запомнил» — из сохранённых фактов ответа (значения словами — `entities/profile-fact`).

## Компоненты
Свои: `OnboardingPage` (вопросы карточками-вариантами, счётчик детей с возрастом и инвалидностью, итог). Из `entities`:
`profile-fact` (`factValueNode`, `keyLabel`). Из `ui`: `Logo`.

## Переходы
«Перейти на главную» → «/»; «Что ассистент знает обо мне» → `/memory`.

## Отличия от макета (с причиной)
- «Зачем спрашиваем» без сумм вычетов (31,20 / 306 / 860 / 120 BYN): ставки — только из таблицы норм (T-040), не
  из текста интерфейса (SPEC P1, LAW-33).
- Нет «Сразу загрузить выписку»: экрана документов ещё нет (T-028, ARCHITECTURE §10.5).

## Готово, когда
`OnboardingPage.test.tsx` (ответы и пропуски, «Изменить», «Пропустить анкету», ошибка) зелёный; `make e2e` — axe 0
на вопросе и итоге при 1440 и 390 (`first-run.spec.ts`).
