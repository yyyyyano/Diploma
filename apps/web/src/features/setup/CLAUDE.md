# Экран `setup` — Первый запуск системы

Маршрут: `/setup` (`routes/_local/setup.tsx`) · доступ: только localhost и только пока система не инициализирована
(иначе `beforeLoad` ведёт на `/login`; на сетевом входе сервер отвечает `NOT_FOUND`).

## Макет
- Исходник: `design/screens/Setup.dc.html`; описание — `design/SCREENS.md` § «Первый запуск системы».
- Скриншоты: `design/screenshots/desktop/Setup.png`, `design/screenshots/mobile-width/Setup.png`.

## Требования SPEC
AUTH-10, ROLE-02, ADM-01, SEC-01 (пароль ≥ 12), NFR-24; состояния — DES-16; доступность — NFR-20.

## Данные (контракт)
- Шаг «Готовим систему» (T-024, NFR-25): после кода и «Продолжить» — `orpc.llm.localModelsProgress` (localOnly, опрос раз в
  2 с, пока не `ready`): полоса «скачано из», пояснения по состоянию; «Войти» доступно сразу — скачивание идёт в фоне.
- Шаг «Готовим систему», правовая база (T-034, LAW-10): `orpc.legalBase.startupProgress` (localOnly, опрос раз в 2 с, пока не
  `ready`): полоса «Загружено N из 28 актов», пояснение про паузу; остановка загрузчика (`LOADER_CONTACT_EMPTY`,
  `LOADER_BLOCKED`, `LOADER_TOO_MANY_ERRORS`) — текст причины и «продолжится сама»; `off` (автозагрузка выключена) —
  раздела нет.
- Изменение: `orpc.identity.setup` (localOnly) — форма на схеме `SetupInput` (email, пароль и необязательный «Контакт для
  загрузчика законов» — email или адрес сайта, пусто — email администратора; пустое поле на сервер не уходит); успех → шаг «Сохраните код
  восстановления» (код из ответа, один раз; `entities/recovery-code`; «Продолжить» — после «сохранил») →
  `/login?created=true`;
  `CONFLICT` (уже настроена) и `NOT_FOUND` (не локальный вход) → `/login`; прочее — текст `errors:<код>`.
- Охрана маршрута: `orpc.identity.status` → `setupAvailable`. Контекст ассистента: `staticData.page = "setup"`.

## Компоненты
Свои: `SetupPage`. Из `ui`: `Logo`. Mantine: `TextInput`, `PasswordInput`, `Button`.

## Переходы
После создания администратора — вход (`/login` с пометкой «Администратор создан»).

## Отличия от макета (с причиной)
- Шаги «Администратор», «Код восстановления» и «Готовим систему» (локальные модели и правовая база) — индикатора из трёх
  шагов нет; поле «Контакт для загрузчика законов» — на первом шаге, под паролем; «Скачать .txt» нет —
  «Скопировать» и запись вручную.
- Подсказка «Минимум 12 символов» вместо «10» макета: прав SPEC (SEC-01, ADR-0016).
