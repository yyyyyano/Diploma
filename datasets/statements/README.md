# Синтетические выписки

Сгенерированы `tooling/synth/statements/` (`make synth-statements`). Банки, счета, продавцы и суммы вымышлены,
реальных выписок и персональных данных здесь нет (NFR-18). Файл случая — `statement.<ext>`, эталон —
`expected.json`: операции, остатки, расхождение цепочки остатков и смысл колонок. Генератор детерминирован:
повторный запуск даёт те же байты (проверяет `tooling/synth/statements/generate.test.ts`).

| Случай | Что проверяет |
|---|---|
| `lesbank-csv-september` | CSV utf-8 с BOM, разделитель «;», даты дд.мм.гггг, суммы «1 234,56», колонки «Приход» и «Расход», остаток. Вымышленный «Лесбанк», карта ****4821. Первая выписка формата — для запоминания. |
| `lesbank-csv-october` | Вторая выписка того же формата, что lesbank-csv-september (другой период и другие операции): разбирается по запомненному формату без модели. |
| `lesbank-csv-changed` | Тот же вымышленный банк, но формат изменился: другой порядок и названия колонок, одна колонка суммы со знаком, даты гггг-мм-дд, суммы «1234.56», колонка валюты. Проверка: изменение формата замечено. |
| `yantar-csv-cp1251` | CSV в windows-1251, дата и время в разных колонках, дата дд.мм.гг, одна колонка суммы со знаком, валюта в колонке, остатков и шапки банка нет (STMT 9.7: остатки и MCC не обязательны). Вымышленный «Янтарьбанк». |
| `puschabank-xlsx` | XLSX с шапкой банка (название, IBAN, период, остатки) над таблицей, настоящие ячейки-даты и числа, колонки «Дебет» и «Кредит». Вымышленный «Пущабанк», IBAN с нулевой контрольной суммой. |
| `hamlet-xls-english` | XLS (BIFF8): английские заголовки, даты мм/дд/гггг, суммы «1,234.56» текстом, валюта USD в шапке, операции от новых к старым. Вымышленный «Hamlet Bank». |
| `lesbank-pdf-multipage` | PDF с текстовым слоем на 3 страницах: шапка таблицы на каждой странице, «Страница N из M» внизу, длинные описания переносятся на вторую строку, минус — U+2212. Остатки в шапке. Вымышленный «Лесбанк». |
| `yantar-pdf-foreign` | PDF карты в BYN с покупками в USD и EUR: сумма в валюте операции, её валюта и сумма в BYN отдельными колонками. Вымышленный «Янтарьбанк», карта ****0907. |
| `csv-injection` | CSV, в двух назначениях платежа — приказы модели («игнорируй правила…», закрывающий тег </document>). Проверка: описание остаётся данными, на разбор не влияет (STMT-12, SEC-10). |
| `csv-balance-mismatch` | CSV, в шапке остатки полной выписки, а одной операции в файле нет: цепочка остатков не сходится, импорт обязан получить пометку «проверьте» (STMT-04 шаг 3). |
| `csv-unknown-headers` | CSV с заголовками, которых нет в словаре эвристики («Проведено», «Поступило», «Выбыло», «Итого на счёте»), дата и время в одной ячейке: колонки определяет модель по небольшому фрагменту. |
| `scan-png` | Скан выписки — картинка PNG (страница, нарисованная контурами букв, с наклоном и размытием). Разбирает модель с изображениями; в тестах её ответ — сценарный, равный эталону. |
| `scan-pdf` | PDF без текстового слоя: на странице одна вложенная картинка-скан. Текста нет — страницы уходят модели. |
