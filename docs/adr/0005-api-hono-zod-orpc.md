# ADR-0005: API — Hono + Zod 4 + oRPC контракт-первым

- **Статус:** Принято
- **Дата:** 2026-10-24
- **Требования:** NFR-10, NFR-19, NFR-21, CHAT-02, OBS-01, OBS-02, SEC-03

## Контекст

Сайт и сервер на одном языке должны делить схемы данных; нужны типизированные ошибки, загрузка файлов,
стриминг ответа ассистента и фоновый прогресс. Сайт не должен импортировать серверный код.

## Решение

- **Hono 4** — тонкая HTTP-оболочка на веб-стандартах (заголовки, request-id, лимиты, статика, два слушателя).
- **Zod 4** — единый язык схем (русская локаль, `z.file()`, JSON Schema); одна схема проверяет форму на сайте
  и вход на сервере.
- **oRPC 1.16, контракт-первым**: `packages/contract` описывает процедуры (`oc.route().input().output().errors()`)
  и зависит только от `zod`, `@orpc/contract`, `@kosht/kernel`; сервер реализует контракт (`implement`) в `api/router.ts`
  модулей, дерево собирает `main/router.ts`; сайт — клиент + `@orpc/tanstack-query`. Тот же роутер отдаёт
  REST/OpenAPI (для `curl`, тестов, документации).
- **Ошибки**: каталог `packages/contract/src/errors.ts` (код → статус, `retryable`); на сервере
  `throw new AppError(КОД, params)`; ответ — форма `ORPCError`: `{ defined, code, status, message: <код>, data: {
  requestId, params } }`; текст — на сайте по коду
  через i18n. Чужая запись — `NOT_FOUND`.
- **Версионирование**: один репозиторий — поля только добавляются, удаление через `deprecated`; `/api/v1` — если
  появятся внешние клиенты.
- **Поток чата** — процедура `chat.send` с итератором событий (интеграция oRPC с AI SDK), «Стоп» — `chat.stop`.
  **Живые сигналы** — `events.stream` (SSE) там же.

## Альтернативы

- **NestJS** — декораторы несовместимы с `erasableSyntaxOnly` (ADR-0002), вторая система маршрутов.
- **tRPC 11** — OpenAPI в альфе, ошибки типизированы слабее, подписки исключены из OpenAPI-режима.
- **ts-rest** — поддержка замерла (последний выпуск 2025-06). **Hono RPC** — события потока не типизируются.
- **OpenAPI + кодогенерация** — два шага сборки.

## Последствия

- Сайт знает о сервере только `@kosht/contract`; правило `web-not-to-server` проверяется.
- `@orpc/server` импортируется только в `api/` модулей, `platform/http` и `main` (правило границ).
- Риск: имена функций интеграции oRPC ↔ AI SDK сверяются с 1.16 в бетонной фазе (шаг 8); запасной путь — маршрут
  Hono `/api/chat` с той же проверкой сессии, оформляется новым ADR.
