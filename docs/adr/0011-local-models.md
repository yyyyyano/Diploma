# ADR-0011: Локальные модели — llama.cpp `llama-server` (Vulkan), whisper.cpp, автоскачивание

- **Статус:** Принято
- **Дата:** 2026-10-24
- **Требования:** NFR-03, NFR-05, NFR-25, LLM-02, LLM-07, PRIV-02, VOICE-03, LAW-23, ADM-50

## Контекст

Машина — Intel Core Ultra 5 225H со встроенной Arc, 36 ГБ RAM, без NVIDIA. Локальные модели нужны как запасной путь
цепочки, как единственный путь для пользователей без облачного согласия и всегда — для эмбеддингов. Пользователь
ничего не скачивает руками.

## Решение

- **`llama-server`** (llama.cpp, релиз с Vulkan, **версия закреплена**) в режиме роутера (`--models-dir`, загрузка и
  выгрузка моделей по запросу, `--sleep-idle-seconds`): чат, изображения, эмбеддинги — одним OpenAI-совместимым API на
  `127.0.0.1:8142`.
- Модели по умолчанию: чат — **Qwen3.5-4B Q4_K_M** (~2,6 ГиБ, мышление выключено; 2B — облегчённая, 9B — опция
  качества); чеки без облака — VLM 2B/4B с **mmproj на CPU** (`--image-max-tokens` 512–1024; через Vulkan «глаз» даёт
  мусор), ~50 с на чек — принято; эмбеддинги — **bge-m3 Q8_0** (вектор 1024) временно, окончательный выбор — замером
  на QA-12 (LAW-23).
- Речь: облако (Groq Whisper) при согласии, иначе **whisper.cpp** large-v3-turbo q5_0 (Vulkan, 3–4 с на фразу,
  `127.0.0.1:8143`); слабая белорусская речь принята — текст всегда показывается на правку (VOICE-02).
- **Автоскачивание** (NFR-25): свой загрузчик в `llm/application/local-models/` — HTTP Range с докачкой, sha256,
  прогресс в админку; каталог `data/models/` (том `models`); минимальный набор ≈ 4,3 ГиБ; старт по событию
  `identity.system-initialized` и из админки.
- **Самотест при старте**: «2+2», эталонный вектор, мини-чек; при «мусоре» — автоматический откат на CPU.
- В контейнере — `devices: /dev/dri` + `group_add: ${RENDER_GID}` (Docker Engine, ADR-0015). Без Python.

## Альтернативы

- **Ollama** — встроенное видеоядро по умолчанию отключено, открытые баги Arrow Lake/Vulkan; плюс только `pull`.
- **OpenVINO** — быстрее prefill, медленнее decode, сложнее установка; опция на потом.
- **`transformers.js` + onnxruntime** для эмбеддингов — работает в Node, но векторы отличаются от GGUF (отдельный индекс).
- **Python-сервис** (FRIDA и т. п.) — второй язык ради одной модели.

## Последствия

- Локальный режим заметно медленнее (≈ 12 токенов/с для 4B) — плашка «Локальный режим: ответы медленнее» (PRIV-02).
- Обновление llama.cpp — отдельная задача с самотестом и сверкой кассет eval.
- Смена модели эмбеддингов — фоновая переиндексация без смены схемы (ADR-0007).
