# ADR-0011: Локальные модели — llama.cpp `llama-server` (Vulkan), whisper.cpp, автоскачивание

- **Статус:** Принято
- **Дата:** 2026-10-24
- **Требования:** NFR-03, NFR-05, NFR-25, LLM-02, LLM-07, PRIV-02, VOICE-03, LAW-23, ADM-50

## Контекст

Машина — Intel Core Ultra 5 225H со встроенной Arc, 36 ГБ RAM, без NVIDIA. Локальные модели нужны как запасной путь
цепочки, как единственный путь для пользователей без облачного согласия и всегда — для эмбеддингов. Пользователь
ничего не скачивает руками.

## Решение

- **`llama-server`** (llama.cpp, релиз с Vulkan, **версия закреплена**) в режиме роутера (`--models-dir`, загрузка и
  выгрузка моделей по запросу, `--sleep-idle-seconds`): чат, изображения, эмбеддинги — одним OpenAI-совместимым API на
  `127.0.0.1:8142`.
- Модели по умолчанию: чат — **Qwen3.5-4B Q4_K_M** (~2,6 ГиБ, мышление выключено; 2B — облегчённая, 9B — опция
  качества); чеки без облака — VLM 2B/4B с **mmproj на CPU** (`--image-max-tokens` 512–1024; через Vulkan «глаз» даёт
  мусор), ~50 с на чек — принято; эмбеддинги — **bge-m3 Q8_0** (вектор 1024) временно, окончательный выбор — замером
  на QA-12 (LAW-23).
- Речь: облако (Groq Whisper) при согласии, иначе **whisper.cpp** large-v3-turbo q5_0 (Vulkan, 3–4 с на фразу,
  `127.0.0.1:8143`); слабая белорусская речь принята — текст всегда показывается на правку (VOICE-02).
- **Автоскачивание** (NFR-25): свой загрузчик в `llm/application/local-models/` — HTTP Range с докачкой, sha256,
  прогресс в админку; каталог `data/models/` (bind-монтирование, а не том — ADR-0015); минимальный набор ≈ 4,3 ГиБ; старт по событию
  `identity.system-initialized` и из админки.
- **Самотест при старте**: «2+2», эталонный вектор, мини-чек; при «мусоре» — автоматический откат на CPU.
- В контейнере — `devices: /dev/dri` + `group_add: ${RENDER_GID}` (Docker Engine, ADR-0015). Без Python.

## Альтернативы

- **Ollama** — встроенное видеоядро по умолчанию отключено, открытые баги Arrow Lake/Vulkan; плюс только `pull`.
- **OpenVINO** — быстрее prefill, медленнее decode, сложнее установка; опция на потом.
- **`transformers.js` + onnxruntime** для эмбеддингов — работает в Node, но векторы отличаются от GGUF (отдельный индекс).
- **Python-сервис** (FRIDA и т. п.) — второй язык ради одной модели.

## Последствия

- Локальный режим заметно медленнее (≈ 12 токенов/с для 4B) — плашка «Локальный режим: ответы медленнее» (PRIV-02).
- Обновление llama.cpp — отдельная задача с самотестом и сверкой кассет eval.
- Смена модели эмбеддингов — фоновая переиндексация без смены схемы (ADR-0007).

## Дополнение T-024 (2026-10-29): загрузчик, роутер, самотест

- **Каталог** (`llm/application/local-models/catalog.ts`): чат Qwen3.5-4B Q4_K_M + mmproj F16 (`unsloth/Qwen3.5-4B-GGUF`),
  bge-m3 Q8_0 (`ggml-org/bge-m3-Q8_0-GGUF`), whisper large-v3-turbo q5_0 (`ggerganov/whisper.cpp`), русская NER
  (`onnx-community/bert-base-NER-Russian-ONNX`, int8). Адреса — `/resolve/<коммит>/…`, sha256 и размеры из метаданных
  LFS на 2026-10-29 (малые файлы NER — посчитаны по файлам); новая версия модели — новая запись.
- **Загрузчик**: Range с докачкой `.part`, sha256, проверка свободного места (`statfs`), прогресс в `llm_local_models`
  (раз в секунду) — worker пишет, api читает опросом раз в 2 с; задача `llm.download-models` (retryable: сеть и 5xx).
  Старт — подписка на `identity.system-initialized` и кнопка в админке; настройка `llm.models-download` выключает
  скачивание (тесты и e2e). Модели в этой фазе не скачиваются (решение пользователя): загрузчик и самотест проверены
  на локальном HTTP-сервере и подставном llama-server; ручная проверка `make up WITH_MODELS=1` — за пользователем.
- **Роутер llama-server** (README b11854): без `--model`, `--models-preset /models/presets.ini` (секции `qwen3.5-4b` и
  `bge-m3` с явными путями, `no-mmproj-offload`, `reasoning-budget = 0`, векторы — `embeddings`, `pooling = cls`),
  `--models-max 2`, `--sleep-idle-seconds 300`. **Видит ли роутер модели, скачанные после старта:** по README список
  обновляет `GET /models?reload=1` — загрузчик шлёт его после скачивания; без него — только перезапуск сервиса.
  Ключи INI (`no-mmproj-offload = true` как флаг) сверены по описанию флагов README, а не запуском: проверить вручную.
- **Самотест**: «2+2» → есть «4» и эмбеддинги (1024 числа, конечные, не нули, «кошка» ближе к «коту», чем к «налогу»;
  файла-эталона нет — без запуска модели его не получить). «Мусор» → пресеты «всё на процессоре» (`n-gpu-layers = 0`),
  выгрузка и перечитывание роутера, повтор; итог — в админке («запасной режим»). Сервис не запущен — не «мусор», а «не
  запущен». Самотест идёт после скачивания и по кнопке «Проверить модели»; при старте процесса отдельного хука у модуля нет.
- **NER** — см. ADR-0009, дополнение T-024.

## Дополнение T-043: whisper.cpp в реестре и голос на сайте

- **Адаптер** — `llm/infrastructure/providers/whisper.ts`: AI SDK умеет транскрипцию только у облачных пакетов, поэтому модель
  написана по спецификации `TranscriptionModelV4`: `POST {llm.whisper-base-url}/inference` (multipart `file`,
  `response_format=json`) → `{ text }`. Запись реестра `whisper/large-v3-turbo-q5_0` и вторая ступень цепочки `transcribe`
  (после Groq Whisper) — миграция `…_llm-whisper`. Шлюз идёт по цепочке до первой ответившей модели без повторов
  (VOICE-03): недоступное облако не задерживает локальную.
- **Формат записи.** whisper-server без ffmpeg понимает WAV, MP3 и FLAC, и WAV строго 16 кГц; `MediaRecorder` даёт webm/opus
  (Chrome, Firefox) или mp4 (Safari). Сайт сам декодирует запись (`decodeAudioData`), пересчитывает в 16 кГц моно через
  `OfflineAudioContext` и пишет WAV ≤ 60 с; сервер проверяет заголовок (SEC-03). ffmpeg в образе не нужен.
- **Язык.** В `compose.yaml` — `-l auto` (по умолчанию whisper-server считает речь английской): русский и белорусский.
- Проверка модели на живой речи и замер времени — ручные, после `make up WITH_MODELS=1` (T-055).
