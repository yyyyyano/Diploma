# ADR-0012: Документы и интеграции — выписки, чеки, Excel, pravo.by, Telegram, НБРБ

- **Статус:** Принято
- **Дата:** 2026-10-24
- **Требования:** PRIV-05, STMT-03…09, RCPT-01…04, RCPT-12, XLS-01…04, LAW-35…39, TG-01…11, SEC-03, NFR-18, R43, R44

## Контекст

Выписки любого банка (PDF, XLSX/XLS, CSV, сканы) должны разбираться автоматически без ручных разборщиков и без
реальных образцов (R44). Фото чеков — с iPhone (HEIC), QR с УИ. Excel — с живыми формулами, без диаграмм (R43).
Законы — только с pravo.by, вежливо. Бот — без публичного адреса.

## Решение

- **Выписки — один универсальный разбор** с автоматическим **запоминанием формата** (STMT-05):
  чтение по виду файла (стратегии): PDF — **unpdf** (pdf.js) + своя сборка строк и колонок по координатам слов;
  XLSX/XLS — **SheetJS CE** из официального тарболла в `vendor/` (на npm устаревшая 0.18.5); CSV — **papaparse** +
  своё определение кодировки (`TextDecoder`); скан — модель с изображениями. Определение колонок — цепочка
  `RememberedFormat` → эвристика → модель по маленькому **замаскированному** фрагменту (только смысл колонок,
  строки разбирает код). Сверка цепочки остатков — `calc`. Качество — на синтетических наборах `datasets/statements`
  (генераторы в `tooling/synth/`).
- **Чеки**: **zxing-wasm** с локальным `.wasm` (не CDN) для QR; **sharp** (поворот по EXIF, уменьшение до 1400–2000 px,
  нормализация, удаление EXIF/GPS перед облаком); **heic-decode** в `worker` (~360 МБ и 2,7 с на 12 Мп). Сервис МНС
  «Проверка чека» автоматически не запрашивается (RCPT-12, reCAPTCHA).
- **Excel**: **ExcelJS** — листы «Операции», «Сводка» (`SUMIFS` по целым столбцам), «Лимиты»; у каждой формулы
  записан и кэш-результат (иначе просмотрщики показывают нули); фильтры, закреплённые заголовки, формат BYN, палитра
  DES. Тест XLS-03 пересчитывает файл независимым движком (HyperFormula — только dev-зависимость тестов).
  Дополнение T-051: версии точные — ExcelJS 4.4.0 (MIT), HyperFormula 3.5.0 (GPL-3.0, `licenseKey: "gpl-v3"`, только
  тесты — правило `hyperformula-only-in-tests`); ExcelJS — только в `xls-export/infrastructure`. Месяц в `SUMIFS` — условия по
  датам (`">="&начало`, `"<"&EDATE(начало;1)`), а не столбец месяца: добавленная вручную строка попадает в нужный месяц; рублёвая
  операция — `H = F`. Файл собирается по запросу (`GET /xls-export`, `z.file()`), не хранится, модуль `files` не нужен; период
  ≤ 60 месяцев (настройка). ExcelJS при чтении теряет результат `0` и `calcPr` — тест это учитывает.
- **pravo.by**: встроенный `fetch` + свой `PoliteFetcher` (один поток, 3–5 с между запросами, лесенка повторов 30 с /
  2 мин / 10 мин, остановка цикла при 403/429 или > 20 % ошибок), честный User-Agent с контактом, **robots-parser**
  на каждый адрес, `HEAD` с `Accept-Encoding: identity` для лёгкой проверки, **cheerio** для разбора, сохранённые
  страницы в `__fixtures__/` для офлайн-тестов и карантин (LAW-39).
- **Telegram**: **grammY** (+ `auto-retry`, `@grammyjs/stream`), long polling под консультативной блокировкой Postgres
  (`pg_try_advisory_xact_lock` в открытой транзакции с пульсом: потеря соединения останавливает опрос); без
  `conversations`/session — состояние в нашей БД, тяжёлое — в очередь процесса по чатам; потоковый ответ —
  `replyWithStream` плагина `@grammyjs/stream` (черновики `sendMessageDraft`, деление на сообщения по 4096 знаков), при
  ошибке черновика ответ уходит одним сообщением (дополнено T-052; прежняя запись — «запасной `editMessageText` ≤ 1/с»).
  `@grammyjs/files` и `transformer-throttler` не нужны: файл скачивается `getFile` + `fetch` с пределом размера за
  портом, лимиты 429 держит `auto-retry`. grammY импортируется только в `telegram/infrastructure/`.
- **НБРБ**: свой клиент с кэшем в БД, запрос по ISO-коду (не `Cur_ID`), учёт `Cur_Scale`, диапазон ≤ 365 дней,
  выходной — последний установленный курс.
- **Нормализация и сравнение названий**: `Az.js` за интерфейсом `Lemmatizer`, `transliteration` + справочник
  алиасов, `fuzzball` в приложении и `pg_trgm` в БД; морфология законов — только Postgres.
- **Приём файлов**: один вход `files` — тип по содержимому (`file-type`), белый список, лимиты, разбор в `worker`
  с таймаутом и лимитом памяти, защита от ZIP-бомб; имя файла никогда не путь.
- **Архив «Мои данные» (PRIV-05, дополнено 2026-10-28, T-016)**: **yazl 3.3.1** — потоковая запись ZIP (одна
  зависимость `buffer-crc32`): записи открываются лениво, байты архива уходят в
  `BlobStore.putStream` кусками, в памяти — только текущий кусок; ошибку источника (pipe её не передаёт) ловит своя
  обёртка `privacy/infrastructure/zip-archive.ts`. Чтение архива в тестах — **yauzl 3.4.0** того же автора, только в
  `@kosht/testing`. Сборка — задача `worker` `privacy.build-export`.

- **Загрузчик pravo.by (дополнено 2026-10-30, T-034; исправлено 2026-10-31, T-041)**: «один поток» и пауза 3–5 с держатся в
  БД, а не в памяти процесса — **аренда очереди** в `legal_loader_state` под `pg_advisory_xact_lock` (короткая транзакция,
  ожидание и HTTP — вне её): запрос идёт, только если `next_request_at` наступил; аренда ставит его в `сейчас + таймаут +
  пауза`, а по окончании запроса (ответ, ошибка, отмена) возвращается — `конец + пауза`. Так пауза отсчитывается от конца
  запроса, а задачи `load-act`, `check-now`, `add-acts`, `daily-check`, `catalog-growth` (у каждой своя очередь pg-boss и
  свой `work()`) и разные процессы не шлют запросы одновременно; ожидающий опрашивает аренду шагом не длиннее паузы.
  Пауза переживает перезапуск; «остановка до следующих суток» — день остановки (`stopped_on`) по поясу системы, а не таймер. Контакт оператора
  попадает в User-Agent и больше никуда. Источник текстов — порт `LegalSource`: `pravo.by` или `fixtures` (настройка
  `legal-base.source`; тесты и стенд e2e — без сети, NFR-11). Контакт с экрана первого запуска передаётся не в нагрузке
  события (нагрузка — только id, OBS-04), а фасадом `identity.loaderContact()`.

## Альтернативы

- **Ручные разборщики под банки по реальным образцам** (R8) — заменено R44.
- **Python (Docling, Tabula)** — второй язык, PyTorch без NVIDIA бесполезен.
- **wasm-xlsxwriter** (диаграммы в Excel) — диаграммы сняты R43; **pivot-таблицы** не пересчитываются сами (XLS-03).
- **archiver** (8.0.0) для архива «Мои данные» — тот же поток, но 9 прямых зависимостей (`async`, `lazystream`,
  `readdir-glob`, `tar-stream`, `zip-stream`…) ради TAR и глобов, которые не нужны; у yazl — одна (`buffer-crc32`).
- **Telegraf** — не обновлялся с 2024-02. **chardet** ошибся на cp1251. **jsQR** — от 1 до 16 с на 12 Мп.

## Последствия

- Новый формат выписки = новая стратегия или запись запомненного формата, а не правка ядра.
- `Az.js` — библиотека 2016 года: держать замену под рукой за интерфейсом.
- Реальные образцы, если появятся, — только обезличенными копиями в `datasets/` (NFR-18).
