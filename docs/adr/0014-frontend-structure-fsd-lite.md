# ADR-0014: Структура фронтенда — FSD-lite и дизайн-система поверх Mantine

- **Статус:** Принято
- **Дата:** 2026-10-24
- **Требования:** DES-00, DES-01, DES-16, NFR-19, NFR-20, CHAT-08

## Контекст

~19 экранов, карточки, которые нужны в нескольких местах (карточка чека — в «Документах», в панели операции и в
чате), агенты, которым нужно однозначное «куда положить код». Полный Feature-Sliced Design даёт 6 слоёв, сегменты и
`@x`-импорты — много решений «в какой слой» для агента; папки по маршрутам через месяц превращаются в клубок.

## Решение

- Слои **`app → routes → features → entities → ui / lib`** с импортом только вниз (проверяет dependency-cruiser:
  `web-layers-down`, `web-feature-isolation`, `web-routes-thin`, `ui-is-presentational`):
  - `routes` — тонкие файловые маршруты TanStack (схема параметров адреса, loader, вызов страницы фичи);
  - `features/<экран>` — экраны из `design/SCREENS.md`, у каждой паспорт `CLAUDE.md`; фича не импортирует другую;
  - `entities/<сущность>` — общие предметные виджеты и хуки данных;
  - `ui` — **дизайн-система** «Пуща и янтарь» поверх Mantine: только представление, без запросов; `ui/theme/tokens.css` —
    копия `design/tokens.css`; «сырые» цвета вне `ui/theme` запрещены (`tooling/checks/no-raw-colors.mjs`);
  - `lib` — клиент oRPC, поток событий, i18n, контекст страницы, мост к ассистенту.
- Связь фич — `Link` с типизированными параметрами, `lib/assistant-bridge`, общие `entities`.
- Состояние страницы — в адресе (Zod-схема в `features/<x>/model/search.ts`).
- Базовые компоненты (~16) делаются в бетонной фазе по `design/kit.css` и `DESIGN.md`; `StatusBadge` без иконки не
  компилируется; `/dev/gallery` показывает все состояния.

## Альтернативы

- **Полный FSD** — слои `pages/widgets` дублируют маршруты TanStack и фичи-экраны.
- **Папки по маршрутам** — копии общих карточек, слабые границы.
- **`packages/ui`** — потребитель один; вынос механический, когда появится второй.

## Последствия

- Экран = одна фича: задача «сделай экран Операции» ограничена `features/operations` (+ при необходимости `entities`).
- Общий виджет, понадобившийся второй фиче, переносится в `entities` в той же задаче.
- Отличие от макета записывается в итог задачи (DES-00), а не молча.
