# Пакет `@kosht/calc` — все числа P1/P2: чистые функции `вход → { value, trace }`

## Назначение
Финансовые, налоговые и проверочные расчёты (P1) с трассой «Откуда эта цифра?» (P2, ADR-0017). Отдельный пакет,
чтобы расчёт нельзя было «случайно» вызвать с БД или на сайте. Правила кода — `.claude/rules/calc.md`.

## Кто использует
`apps/server` (модули fin, tax, budgets, afford, receipts, statements, weekly…); `apps/web` — запрещено (P1).

## Публичный API
- Вход: `packages/calc/src/index.ts`. `Calc<T> = { value, trace }`; лист трассы — `node(key, value, { refs, note })`
  (число — только целое, деньги — как `Money.of`).
- Помощники трассы над `Money`: `sum` (≥ 1 слагаемого), `sub` (уменьшаемое — первый аргумент трассы), `mul` (на
  целое количество), `mulRate` (ставка — `Calc<number>` в базисных пунктах, `1300` = 13 %), `avg`, `round`.
- Округление — только явное, `{ rounding: RoundingRule }`, правило «режим-шаг»; в трассу пишется
  `note: "rounding=<правило> step=<шаг>"`:
  - `half-up` — половина от нуля, симметрично: −0,5 → −1, 0,5 → 1, −1,5 → −2, 1,5 → 2;
  - `half-even` (банковское) — к чётному: −0,5 → 0, 0,5 → 0, −1,5 → −2, 1,5 → 2;
  - `floor` — вниз (−0,5 → −1, 0,5 → 0); `ceil` — вверх (−0,5 → 0, 0,5 → 1);
  - шаг: `kopeck` = 1 минимальная единица, `ruble` = 100 (у всех поддерживаемых валют две цифры после запятой).
- Показатели: `fin/` — `freeBalance` (FIN-20, ключ `fin.freeBalance`; входы — `fin.averageIncome`,
  `fin.obligation.<группа>`).
- `TRACE_KEYS` / `TraceKey` (`trace-keys.ts`) — общий реестр ключей трассы показателей и их входов: у каждого есть
  подпись в словаре `formulas` (тест словаря `@kosht/i18n`).
- Соглашения: деньги — `Money` в копейках; «сегодня», ставки, пороги, курсы — во входе; `key` — ключ подписи из
  словаря `formulas`.

## Можно зависеть от
Только `@kosht/kernel` (правило `calc-only-kernel` в `.dependency-cruiser.mjs`); `fast-check` — только в тестах.

## Запреты
- Ни БД, ни сети, ни файлов, ни `Date.now()`/`new Date()`/`Math.random()`/`Intl` (проверяет `calc-no-clock.mjs`).
- Без побочных эффектов и глобального состояния; без `number` с рублями и `toFixed`; ставки и суммы — только входом.

## Как тестировать
- `pnpm vitest run packages/calc`; покрытие — строки ≥ 95 %, ветви ≥ 90 % (`CONSTRAINTS.md`, `vitest.config.ts`).
- Каждый пример из SPEC — отдельный тест с номером требования в `describe`; свойства (порядок слагаемых,
  `sub(sum(a, b), b) = a`, идемпотентность и монотонность `round`, среднее между min и max) — fast-check.

## Подводные камни
- Внутри помощников — BigInt; результат вне безопасного диапазона `Number` — `RangeError`, разные валюты —
  `CurrencyMismatchError`: пересчёт по курсу — явный шаг расчёта с курсом в `refs`.
- Функции разбиения целого на части пока нет — её добавит задача первого потребителя (с fast-check «сумма частей = целое»).
