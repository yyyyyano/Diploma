# Пакет `@kosht/i18n` — тексты и форматы: словари ru, типизированные ключи, суммы и даты

## Назначение
Весь текст для человека (NFR-19) — в одном месте для сайта, бота, писем и уведомлений. Отдельный пакет: тексты
меняются ради интерфейса и не тянут за собой сервер. Правила — `.claude/rules/i18n.md`.

## Кто использует
`apps/web` (react-i18next на тех же `resources`, T-008), `apps/server` (бот, письма, уведомления).

## Публичный API
- Вход: `packages/i18n/src/index.ts`.
- `createT(language = "ru")` — свой экземпляр i18next без React; `T` — тип перевода. Ключ — `<ns>:<ключ>`
  (`common:relativeDay.today`); несуществующий ключ или пространство имён не компилируется.
- `resources` (`{ ru: { common, errors, formulas, tools, mail, policy, shell, ui, auth, setup, accounts, assistant, mailbox, settings, documents } }`), `NAMESPACES`, `LANGUAGES`, `Language`, `Namespace`.
- `ratesTexts` (`locales/ru/rates.ts`, T-040) — словарь «Таблицы ставок»: есть в типах ключей (`rates:…`), но не в `resources`/`NAMESPACES` — страница регистрирует его
  сама (`addResourceBundle`), чтобы он не ехал в первую загрузку сайта.
- Словари (`locales/ru/`): `common` (общее; множественные числа `count.operations_*`), `errors` — по одному тексту на
  `ErrorCode` контракта (`satisfies Record<ErrorCode, string>`), `formulas` — подписи ключей трассы calc
  (каждый ключ `TRACE_KEYS` из `@kosht/calc`; `unknown` — запасная), `tools` — подписи шагов агента по имени инструмента (`fallback` — запасная), `mail` — письма
  системы (собирает модуль `mail` на сервере), `policy` — политика ПД и тексты согласий (PRIV-01/02) и
  `CONSENT_VERSIONS` — версии этих текстов (сервер хранит версию с согласием; правка текста — новая версия); сайта: `shell` —
  каркас (меню DES-15, нижняя панель, экраны ошибки), `ui` — подписи дизайн-системы (ⓘ, «Отменить», «Закрыть»); экранов — `auth` (вход), `setup` (первый
  запуск), `accounts` (счета; `count` — «1 счёт», «3 счёта», «5 счетов»), `operations` (экран «Операции»: таблица, фильтры, форма, карточка, история), `assistant` (чат), `mailbox` (локальный
  почтовый ящик), `settings` (настройки пользователя), `documents` (выписки: предпросмотр импорта, «Исправить колонки», откат), `profile` (факты профиля, анкета, «Что ассистент знает обо мне»;
  `value.children` — «1 ребёнок», «2 ребёнка», «5 детей»; `value.age` — «1 год», «3 года», «17 лет»); `auth` — вход, регистрация, подтверждение адреса.
- Форматы (DES-17): `formatMoney(money)` — «1 234,56 BYN», «−840,00 BYN» (между разрядами и перед кодом U+00A0,
  минус U+2212); `formatMoneyParts(money)` — те же части отдельно `{ negative, amount, currency }` (сайт: валюта
  мельче, знак «+»/«−» по смыслу операции); `formatDate(date)` — «21.10.2026»; `formatRelativeDay(date, today)` — сегодня, вчера, завтра,
  послезавтра, «через N дн.» / «N дн. назад» до ±7 дней, дальше — `formatDate`; `formatTime(time)` — «08:47» из «чч:мм» и «чч:мм:сс» (иное — `RangeError`); `formatFileSize(bytes)` — «820 Б»,
  «1,5 КБ», «18,4 МБ» (единицы по 1024, десятые без «,0», U+00A0 перед единицей).
- `parseMoney(text, currency)` — ввод суммы человеком («2 400,50», «2400.5», «−12», пробелы любые) → целые копейки
  `Money` строкой, без float; не сумма (буквы, три знака после запятой) — `undefined`.
- Множественные числа: `_one` (1, 21, 101), `_few` (2–4, 22), `_many` (0, 5–20, 25, 111) **и `_other`** (дроби);
  число в тексте — `{{count, number}}` («1,5 операции»): это `Intl`, разделитель разрядов от 1000 ставит ICU.

## Можно зависеть от
`@kosht/kernel`, `@kosht/contract`, `i18next` (версия — `catalog:`); в тестах ещё `@kosht/calc` — правило
`i18n-allowed-deps` в `tooling/architecture/rules.ts`.

## Запреты
- Импорт приложений и серверного кода; React — только на сайте (react-i18next), не здесь.
- Склейка строк вместо параметров; текст для человека вне словаря; часы (`Date.now()`) — «сегодня» только входом.

## Как тестировать
- `pnpm vitest run packages/i18n`; «не компилируется» (чужой ключ) — тест с `@ts-expect-error`.
- Соответствие коду — `resources.test.ts`: тексты на все коды каталога ошибок, подпись `fin.freeBalance`.

## Подводные камни
- `escapeValue: false` — экранирует канал вывода (React, письмо, бот); глобальный `i18next` не трогается.
- `formatMoney` — BigInt и разряды руками, без `Intl` и float: ICU ставит то U+00A0, то U+202F, float теряет копейки;
  у всех валют две цифры после запятой. Даты — календарная арифметика без `Intl` и часов: пояс (NFR-23) учтён в
  `LocalDate.fromInstant`, «сегодня» — аргумент из `Clock.today()`.
