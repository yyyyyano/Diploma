## 0. Главное одним абзацем

- На pravo.by есть **два разных типа страниц про один акт**: (1) текст в актуальной редакции из «тематических банков данных» — `https://pravo.by/document/?guid=3871&p0=<ID>` — HTML с классами `article`/`point`, есть не у всех актов; (2) карточка из Национального реестра — `https://pravo.by/document/?guid=3961&p0=<ID>` (или `guid=11031`) — есть у любого акта, но там только реквизиты, список изменяющих актов и ссылка на etalonline [В].
- Из 27 ключевых актов по 10 областям **22 доступны HTML-текстом**, **5 — только карточка** (ПСМ № 778, ПСМ № 935, ПСМ № 134, ПСМ № 182, Закон № 369-З о гарантировании вкладов). Все 10 областей имеют хотя бы один акт с актуальным текстом; полностью закрыты 7 областей, частично — 3 (потребители, банки/вклады, образование/медицина) [В].
- **Указ № 530 «О страховой деятельности» утратил силу 23.04.2025** (Указ № 108 от 18.03.2025, Перечень утративших силу, п. 2), страховое регулирование теперь — Закон № 344-З от 05.01.2024 «О страховой деятельности» и Указ № 108 «О страховании». Из списка проекта 530 надо убрать [В].
- Истории редакций на pravo.by **нет**. Накопить её можно только своими снимками вперёд (≈2,7 МБ gzip на весь набор за снимок) [В].
- Обнаружить изменение можно без API: карточка акта (список изменяющих актов с датами) + заголовок текста + `Content-Length` на HEAD [В].
- Нужна осторожность: в тексте отражены только вступившие в силу изменения, а карточка уже показывает принятые, но ещё не вступившие (у 8 из 22 актов с HTML есть такая «очередь») [В факт, С интерпретация].

## 2. История редакций

### 2.1 Что есть на pravo.by [В]

- Пользовательского выбора «редакция на дату» **нет**. Параметры `p1`, `p2`, `p5`, `date` в URL текста Закона № 90-З не меняют содержимое (md5 идентичен; `p2` лишь убирает обёртку `<html>`).
- Есть **накопительный список изменений** в шапке текста («Изменения и дополнения: Закон … от … № … (Нац. реестр …, N/NNNN) <ID>») и на карточке («Акты, изменяющие (дополняющие) документ» с номером и датой регистрации в реестре) [В]. В шапке НК виден и этапный механизм: один и тот же закон повторяется с пометками «внесены изменения…, вступившие в силу 1 января 2026 г. и 1 июля 2026 г., за исключением … 1 января 2027 г.» [В] (https://pravo.by/document/?guid=3871&p0=Hk0200166).
- Тексты самих изменяющих актов: начиная с 2012 г. на карточке есть ссылки `guid=12551&p0=<ID>` → страница с PDF-сканом `/upload/docs/op/<ID>_<unixtime>.pdf` (unixtime = дата опубликования по Минску, например `P32500095_1741813200` = 13.03.2025) [В]. До 2012 г. в карточке акта ссылок на изменяющие акты нет [В] (в карточке НК ссылки начинаются с п. 16, 2012 г.).
- **Важно:** `Disallow: /upload/docs/op/` в https://pravo.by/robots.txt [В] — PDF автоматически скачивать нельзя; допустимо только вручную или после письменного разрешения.
- Страница архива официального опубликования https://pravo.by/ofitsialnoe-opublikovanie/arkhiv/ — навигация по годам 2011–2026 и месяцам [В] (содержимое архива я не разбирал).
- Wayback Machine: проверить не удалось (archive.org отвечает 429 с моего IP, web.archive.org недоступен инструменту) [Н].

### 2.2 Как восстановить историю

1. **Вперёд — собственные снимки (реализуемо, рекомендуется).** Хранить для каждого отслеживаемого акта: сырой HTML (или нормализованный текст по статьям `class="article" id=N`), блок «Изменения и дополнения», дату снимка, набор ID изменяющих актов с карточки. Объём: 19 ключевых текстов = 20 МБ сырого HTML, **≈2,7 МБ в gzip на один полный снимок** (НК Особенная часть — 644 КБ, ГК — 362 КБ, Кодекс об образовании — 245 КБ) [В]. С дедупликацией (хранить только изменившиеся статьи) — на порядки меньше.
2. Частота. Недельного снимка недостаточно для точной даты вступления этапов: текст меняется **без нового акта в реестре**, когда наступает дата этапа (в шапке НК: «вступят в силу 1 января 2027 г.») [С]. Поэтому: парсить из шапки даты «вступят в силу …» и ставить внеплановый снимок на следующий день после каждой такой даты + ежедневный дешёвый опрос (раздел 3).
3. **Назад — только частично и вручную.** По карточке можно получить полный перечень изменяющих актов и даты регистрации, а для 2012+ — PDF изменяющих законов; применять поправки «заменить слова…» к старому тексту — юридическая редакторская работа, не автоматика. Первоначальной редакции старых актов (до 2012) на pravo.by в HTML нет [С]. Для MVP это не стоит делать.
4. Практический режим для продукта: ответ всегда «по редакции на дату снимка X» + список изменяющих актов с карточки; вопросы «как было на дату Y до первого снимка» — честный отказ «нет данных об этой редакции». Дополнительно хранить diff между снимками, чтобы сообщать «статья изменена».
5. Платный путь — ЭТАЛОН (на сайте сказано, что там есть «будущая редакция» и редакции, https://pravo.by/pravovaya-informatsiya/dostup-k-pravovoy-informatsii/rasprostranenie-pravovoy-informatsii/) — по условию задачи не используем.

### 3.2 Рекомендуемая схема (все запросы разрешены robots.txt) [С — это проектное решение]

1. **Ежедневно** по каждому отслеживаемому ID: GET карточки (`guid=3961`), распарсить множество ID изменяющих актов и поле «Дата ограничения действия». Новый ID в множестве = событие «принят изменяющий акт» (в карточке он указан с датой регистрации в реестре, например № 168-З и № 170-З — 22.07.2026; задержку между регистрацией и появлением в карточке я не измерял) [В/Н].
2. **Ежедневно** HEAD текста: смена `content-length` → GET текста (gzip: 164 КБ вместо 1,1 МБ у НК), пересчитать шапку и хэши статей.
3. **Очередь вступления:** `ID из карточки − ID из шапки` (для актов 2012+) = принятые, но не внесённые в текст изменения. На 21.10.2026 такая очередь есть у НК (№ 170-З), Банковского кодекса, ГК (№ 133-З, 150-З, 168-З), ТК, Кодекса об образовании (№ 150-З, 168-З), Закона № 344-З (№ 150-З), КоАП (№ 173-З) [В]. Закон № 150-З (01.06.2026) в основной части вступает 01.07.2027 (по новости pravo.by https://pravo.by/novosti/novosti-pravo-by/2026/june/93741/ и сообщениям ilex.by; сам закон не открывал) [С], что объясняет его отсутствие в тексте ТК/ГК/Банковского; Жилищный кодекс его уже содержит [В]. Вывод: текст на pravo.by — **действующая на сегодня** редакция, изменения добавляются, когда начинают вступать в силу [С, не подтверждено официальным документом].
4. Раз в сутки — список «Новые поступления» за вчера для поиска актов «Об изменении…» и для обнаружения новых актов, которых ещё нет в наборе.
5. Парсить даты «вступят в силу …» в шапке и планировать внеплановые проверки.

### 3.3 Защита от ботов, лимиты, правила сайта

- **Блокировка по User-Agent** [В]: `curl/…`, `python-requests/…`, `Python-urllib/…` → **403** с текстом «Forbidden / Transaction ID: …»; свой UA (`KoshtBot/1.0 (+контакт)`), пустой UA и браузерный UA → 200. Капчи и Cloudflare не видел (заголовков `cf-*` нет). Рекомендация: честный UA с контактом + e-mail для связи, не маскироваться под браузер.
- **Лимиты:** 30 последовательных + 20 параллельных запросов подряд к карточке — все 200; время ответа 2–4 с на карточку [В]. Жёсткий лимит не обнаружен, но верхнюю границу не выяснял; для ежедневного опроса ~30 актов хватит одного запроса в 3–5 с.
- **robots.txt** (https://pravo.by/robots.txt) [В]: `User-agent: *`; `/document/` **не закрыт**; `/natsionalnyy-reestr/novye-postupleniya/` и `/ofitsialnoe-opublikovanie/novye-postupleniya/` не закрыты (есть только `Clean-param: p0&p1`); закрыты: `/bitrix/`, `/search/`, `/upload/docs/op/` (PDF официального опубликования), `/natsionalnyy-reestr/poisk-v-reestre/?*`, `/pravovaya-informatsiya/pravovye-akty-po-temam/poisk-v-tbd/?*`, `/pravovaya-informatsiya/bank-sudebnykh-resheniy/`, любые `?print=`, `?action=`, `*paging`, `*.aspx*`, `*/index.php`. Crawl-delay не задан.
- **Правила использования**: в подвале главной (и других страниц разделов) — «При использовании материалов активная гиперссылка на pravo.by (право бай) обязательна.» [В] (https://pravo.by/). Страницы «Общие сведения», «Доступ к порталу», «Контакты» (https://pravo.by/o-portale/…) не содержат условий использования и ничего про автоматизированную загрузку [В]; отдельного договора/ToS для pravo.by я не нашёл [С]. На страницах самих текстов (`guid=3871`) подвал: «Дизайн — © Национальный центр законодательства и правовой информации, 2003-2026» без отдельных условий [В].
- Правовой фон [С]: ст. 7 п. 1 Закона № 262-З «Об авторском праве и смежных правах»: не являются объектами авторского права «официальные документы (правовые акты, судебные постановления, иные документы административного и судебного характера, учредительные документы организаций), а также их официальные переводы» (цитата с WIPO Lex, https://www.wipo.int/wipolex/en/text/597525 — русский текст, редакция с поправками до 2023 г.; самого закона на pravo.by текстом нет, только карточка). Это относится к текстам актов, но не гарантирует отсутствие прав НЦЗПИ на **сводную редакцию/базу данных** [Н — вопрос к юристу]. ## 5. Что это значит для продукта

- **Покрытие:** 10 из 10 областей имеют актуальные HTML-тексты на pravo.by. Полностью закрыто 7 (налоги, жильё, труд, пособия/пенсии/семкапитал, договоры/страхование/транспорт, семья, штрафы), частично 3: потребители (нет ПСМ № 778/935/134), банки/вклады (нет Закона № 369-З о гарантиях; Банковский кодекс и ГК есть), образование/медицина (нет ПСМ № 182 о платных медуслугах; Кодекс об образовании и Закон о здравоохранении есть). По списку из 27 ключевых актов: 22 текстом, 5 нет [В].
- **Правки в список актов:** Указ № 530 удалить (утратил силу 23.04.2025), заменить на Закон № 344-З + Указ № 108; Указ № 13 (2012) утратил силу с 01.06.2025 — актуален Указ № 95 [В].
- **История редакций:** на pravo.by её нет. Реализуема **только вперёд**: еженедельные снимки недостаточны (текст меняется по датам вступления без нового акта), нужен ежедневный лёгкий опрос карточек + HEAD текстов и внеплановые снимки на даты этапов. Хранение недорогое (≈2,7 МБ gzip за полный снимок; с дедупликацией по статьям — килобайты). Прошлое до запуска не восстановить автоматически [В/С].
- **Честность ответов:** показывать пользователю «редакция на ДД.ММ.ГГГГ (снимок), изменения по карточке: …» и предупреждать, когда у акта есть принятые, но не вступившие изменения (очередь из п. 3.4 — сейчас есть у НК, ГК, Банковского кодекса, ТК, Кодекса об образовании, КоАП, Закона № 344-З) [В].
- **Технические риски:** блокировка стандартных UA (использовать свой UA с контактом), 2–4 с на ответ, нет ETag/Last-Modified, структура HTML может измениться (опираться на `class="article"/"point"`, `id`), PDF через `/upload/docs/op/` автоматом не брать.
- **Юридический остаток:** гиперссылка на pravo.by обязательна (подвал главной); запрет автоматической загрузки не найден, robots.txt `/document/` разрешает; права НЦЗПИ на сводную редакцию не проверены — одно письмо в НЦЗПИ и консультация юриста до публичного запуска.
